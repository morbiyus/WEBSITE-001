4. DATABASE CONFIGURATION AND SETUP INSTRUCTIONS
================================================================================

To enable full Supabase authentication, follow these steps:

STEP 1: Create a Supabase Project
  1. Go to https://supabase.io and sign up (free tier available)
  2. Create a new project
  3. Note the project URL and anon key

STEP 2: Configure Email Settings (Optional)
  1. In Supabase Dashboard → Authentication → Settings
  2. Enable email confirmations if desired
  3. Set up SMTP provider for actual email messages
  (Note: Per requirement #1, email verification is disabled by default,
   but Supabase can send verification emails if enabled)

STEP 3: Set Up Database (Auto-created)
  Supabase automatically creates:
  - auth.users table (managed by Supabase)
  - Profile metadata via options.data in signUp
  - No manual schema required for basic functionality

STEP 4: Enable Email Auth (If Needed)
  1. Go to Authentication → Providers → Email
  2. Enable "Email password sign-up"
  3. Configure SMTP if sending actual emails

STEP 5: Set Environment Variables in Vercel
  1. Go to Vercel Dashboard → your project → Settings → Environment Variables
  2. Add:
     - VITE_SUPABASE_URL: https://your-project.supabase.co
     - VITE_SUPABASE_ANON_KEY: your_anon_key
     - SESSION_SECRET: random_32_byte_hex_string
  3. Deploy: vercel --prod

STEP 6: Test the Application
  1. Visit https://vazedgame.vercel.app
  2. Test registration, login, logout
  3. Verify session persistence
  4. Test all 12 test scenarios (Section 3.5)
